# 유튜브 영상 → 자막 마크다운

yt-dlp로 영상·자막을 받아 **자막 전문 문서**와 **요약 문서** 두 개를 남긴다.

## 워크플로

1. **저장 위치 확인** — 사용자가 폴더를 지정하지 않았으면 작업 중인 주차 폴더(`week-N/class/`)를 쓴다. 되묻지 말고 정하고 결과에 명시한다.
2. **다운로드** — `scripts/fetch.ps1` 실행. yt-dlp가 없으면 알아서 winget으로 설치한다.
3. **자막 정리** — `scripts/srt-clean.ps1`로 롤업 중복을 제거한다. **직접 손으로 세지 말 것.**
4. **자막 전문 문서 작성** — 아래 템플릿. ASR 오류를 문맥에 맞게 보정하되 **원본을 반드시 함께 남긴다.**
5. **요약 문서 작성** — 아래 템플릿. 전문 문서로 상호 링크.
6. 사용자가 요청하면 커밋한다.

## 스크립트

PowerShell 실행 정책 때문에 **`-ExecutionPolicy Bypass`가 필수**다.

```bash
# 영상 + 한국어 자막
powershell -NoProfile -ExecutionPolicy Bypass -File ".claude/skills/youtube-transcript/scripts/fetch.ps1" \
  -Url "<URL>" -OutDir "week-4/class"

# 자막만 / 영상만
... -SubsOnly          # 영상 건너뛰기
... -NoSubs            # 자막 건너뛰기
... -Langs "ko,en"     # 언어 지정(쉼표 구분, 하나씩 시도)

# srt → 중복 제거된 전문 + 타임코드 표
powershell -NoProfile -ExecutionPolicy Bypass -File ".claude/skills/youtube-transcript/scripts/srt-clean.ps1" \
  -Path "week-4/class/<파일>.ko.srt" -Out "/tmp/clean.md"
```

`-Out`으로 **파일에 쓸 것.** 콘솔로 받으면 한글이 깨져 보인다(파일 내용은 멀쩡하지만 읽기 어렵다).

## 파일명 규칙

원본 영상 파일명은 yt-dlp가 정한 대로 두고, 문서만 짧게 만든다.

- 자막 전문 → `<주제-케밥케이스>-자막전문.md`
- 요약 → `<주제-케밥케이스>-요약.md`

예: `팀쿡-갤럭시-환승-자막전문.md`, `팀쿡-갤럭시-환승-요약.md`

## 템플릿 · 자막 전문

````markdown
# {영상 제목}

> **출처** {채널명} {코너명}
> **원본** {URL}
> **길이** {M분 S초} ({N}초)
> **자막** {유튜브 자동 생성 자막(ASR) 기반 — 수동 자막 미제공 / 채널 제공 수동 자막}

---

## 자막 전문

{중복 제거 후 문단으로 재구성. 문장 부호를 살리고 3~6문단으로 나눈다.
 ASR 오류는 문맥에 맞게 보정한다.}

---

## 타임코드별 원본 자막

{srt-clean.ps1이 뽑아준 표를 그대로. 보정 없는 원문이어야 검증에 쓸 수 있다.}

| 시각 | 내용 |
|---|---|
| 00:00 | ... |

---

## 자동 생성 자막 보정 내역

위 "자막 전문"은 음성인식 오류를 문맥에 맞게 보정한 것입니다. 보정한 부분은 다음과 같습니다.

| 원본(ASR) | 보정 | 비고 |
|---|---|---|
| {원문} | {보정} | {인명/제품명 인식 오류 등} |

> ⚠️ 원본이 자동 생성 자막이므로 고유명사·수치는 원본 영상으로 교차 확인이 필요합니다.
````

- {사실}

|---|---|

## 알아둘 함정

- **PATH** — winget이 PATH를 고쳐도 이미 떠 있는 셸에는 반영되지 않는다. `fetch.ps1`이 매번 레지스트리에서 다시 읽는다. 수동 실행 시엔 새 터미널을 열 것.
- **번역 자막 429** — 원어 외 언어(`en` 등)는 유튜브 번역 캡션 엔드포인트라 `HTTP 429`가 잦다. 재시도·지연을 줘도 막힐 때가 있다. **실패해도 원어 자막은 살리고, 못 받았다고 사용자에게 알린다.** 시간을 두면 대개 풀린다.
- **파일명 대괄호** — yt-dlp 제목에 `[지금이뉴스]` 같은 대괄호가 흔한데 PowerShell이 와일드카드로 해석한다. 경로를 다룰 땐 **`-LiteralPath`**를 쓴다.
- **Windows 금지 문자** — yt-dlp가 `"` → `＂`, `/` → `⧸` 같은 유사 유니코드로 치환한다. 정상이다. 문서에서 파일을 참조할 땐 치환된 실제 이름을 쓴다.
- **롤업 자막** — 자동 생성 자막은 같은 문장이 여러 블록에 겹친다. 87블록이 실제로는 43줄인 식이다. 반드시 `srt-clean.ps1`을 거친다.
- **자막 유무 확인** — `yt-dlp --list-subs <URL>`. 출력이 "Available automatic captions"뿐이면 수동 자막이 없는 것이고, 정확도를 문서에 명시해야 한다.
- **AV1 코덱** — 기본 최상위 포맷이 AV1로 잡힐 때가 많다. 구형 플레이어 호환이 필요하면 `-f "bv*[vcodec^=avc]+ba/b"`로 H.264를 받는다.
- **요약의 해석 분리** — 「짚어볼 점」은 영상에 없는 내용이다. 사실 요약과 섞지 말고, 결과 보고 때 해석임을 밝힌다.
