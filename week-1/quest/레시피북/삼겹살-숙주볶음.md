# 삼겹살 숙주볶음 (15분)

![등불 켜진 밤의 부엌에서 삼겹살 숙주볶음에 밥을 곁들여 먹는 사람 — 지브리풍 일러스트](삼겹살-숙주볶음.png)

> 기름 두를 필요 없는 저녁. 삼겹살 기름으로 숙주를 볶으면 그게 다다.

- **소요 시간** 15분
- **분량** 2인분
- **난이도** 쉬움

## 재료

- 삼겹살 300g — 3~4cm 폭으로 자르기 (대패삼겹살이면 그대로)
- 숙주 300g (1봉지) — 찬물에 헹궈 체에 밭쳐 물기 완전히 빼기
- 대파 1대 — 어슷썰기
- 마늘 4쪽 — 편썰기
- 청양고추 1개 — 어슷썰기 (선택)
- 참기름 1작은술
- 통깨 약간

### 양념장

| 재료 | 분량 |
|---|---|
| 간장 | 2큰술 |
| 굴소스 | 1큰술 |
| 맛술(또는 청주) | 1큰술 |
| 설탕 | 1작은술 |
| 다진 마늘 | 1큰술 |
| 후추 | 약간 |

## 만드는 법

1. **준비 (4분)**
   양념장을 미리 섞어둔다. 숙주는 헹군 뒤 체에 밭쳐 물기를 탈탈 턴다.
   *숙주에 물이 남아 있으면 볶는 순간 물이 쏟아져 나와 국물볶음이 된다. 물기 빼기가 이 요리의 전부다.*

2. **삼겹살 굽기 (5분)**
   기름 두르지 않은 팬을 센불로 달구고 삼겹살을 펼쳐 넣는다. 건드리지 말고 2분, 뒤집어 2분 더 굽는다. 노릇해지면 팬에 고인 기름을 1큰술만 남기고 덜어낸다.
   *기름을 다 두면 느끼하고, 다 버리면 숙주가 팬에 눌어붙는다.*

3. **향 내기 (2분)**
   마늘 편과 대파 흰 부분, 청양고추를 넣고 향이 올라올 때까지 볶는다.

4. **양념 입히기 (1분)**
   양념장을 팬 가장자리에 둘러 붓고 30초간 고기에 코팅하듯 볶는다.
   *가장자리에 부어야 간장이 지글 하고 살짝 타면서 불맛이 난다.*

5. **숙주 넣기 (2분)**
   불을 최대로 올리고 숙주와 남은 대파를 넣는다. 뚜껑은 절대 덮지 말고 뒤집듯이 30초~1분만 크게 휘젓는다. 숙주가 살짝 숨이 죽으면 바로 불을 끈다.
   *숙주는 잔열로도 계속 익는다. "덜 익었나?" 싶을 때 끄는 게 딱 맞다.*

6. **마무리 (1분)**
   참기름과 통깨를 두르고 한 번 섞어 바로 접시에 옮긴다.
   *팬에 두면 아삭함이 사라진다. 담는 것까지가 조리다.*

## 곁들이면 좋은 것

- **흰쌀밥** — 남은 양념에 밥을 비벼 먹으면 한 그릇이 더 나온다
- **쌈장 또는 새우젓** — 삼겹살만 따로 집어 먹을 때 찍어 먹으면 좋다
- **깻잎** — 숙주째 싸 먹으면 느끼함이 확 잡힌다
- 소주, 그리고 시원한 물김치

## 팁

- 삼겹살 대신 **목살**, **베이컨**, 또는 **차돌박이**로 바꿔도 그대로 된다. 기름이 적은 목살이면 식용유 1큰술을 먼저 두른다
- 짜면 숙주를 한 줌 더, 싱거우면 굴소스를 1작은술씩 추가한다. 간은 숙주를 넣기 **전**에 맞춰야 한다 — 숙주가 들어가면 물이 나와 간이 옅어진다
- 매운맛을 원하면 4번에서 고춧가루 1작은술이나 고추기름 1작은술
- 물이 흥건해졌다면 실패가 아니다. 불을 최대로 올려 30초 더 볶아 날리거나, 밥을 넣고 볶음밥으로 돌린다
