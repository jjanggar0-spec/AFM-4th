# 매콤 짬뽕 (2인분)

![매콤 짬뽕 완성](짬뽕-완성.png)

## 재료

![짬뽕 재료](짬뽕-재료.png)

**면·육수**
- 중화면 2인분 (없으면 우동면)
- 물 1.2L, 다시멸치·다시마 육수 또는 닭육수 (치킨스톡 1개 + 물)

**해산물**
- 오징어 1/2마리, 새우 6마리, 홍합 10개, 바지락 한 줌
- (냉동 해물믹스 200g으로 대체 가능)

**채소**
- 양배추 1/6통, 양파 1/2개, 대파 1대, 애호박 1/4개
- 목이버섯 or 표고버섯 3개, 청경채 2포기
- 마늘 5쪽 (다진 것)

**양념**
- 고춧가루 3큰술 (굵은 것 2 + 고운 것 1)
- 식용유 3큰술 + 참기름 1작은술
- 간장 1.5큰술, 굴소스 1큰술
- 청양고추 2개 (매운맛 조절)
- 소금·후추 약간

## 만드는 법

**1. 고추기름 만들기 (핵심)**
팬에 식용유 3큰술을 넣고 **약불**에서 다진 마늘·대파 흰 부분을 볶아 향을 냅니다. 불을 끄고 고춧가루를 넣어 잔열로 30초간 저어주세요. 센 불에서 고춧가루를 볶으면 바로 타서 씁쓸해집니다.

![고추기름 내기](짬뽕-고추기름.png)

**2. 채소 볶기**
다시 센 불로 올리고 양파 → 양배추 → 애호박 → 버섯 순으로 넣어 강하게 볶습니다. 웍을 흔들며 2~3분, 채소 가장자리가 살짝 그을리면 불맛이 납니다.

![채소 볶기](짬뽕-채소볶기.png)

**3. 해산물 + 간장**
해산물을 넣고 30초 볶은 뒤, **팬 가장자리에** 간장 1.5큰술을 둘러 넣습니다. 뜨거운 팬에 닿으며 나는 탄 간장 향이 짬뽕 맛의 절반입니다.

![해산물 넣고 간장 두르기](짬뽕-해산물.png)

**4. 육수 붓고 끓이기**
육수 1.2L를 붓고 굴소스 1큰술, 청양고추를 넣어 센 불에 5~7분 끓입니다. 거품은 걷어내고, 마지막에 소금·후추로 간을 맞춥니다.

![육수 붓고 끓이기](짬뽕-육수끓이기.png)

**5. 면 삶기**
별도 냄비에 면을 포장 시간대로 삶아 **찬물에 헹군 뒤** 뜨거운 물에 다시 한 번 데칩니다. 헹궈야 국물이 탁해지지 않고 면이 쫄깃합니다.

![면 따로 삶기](짬뽕-면삶기.png)

**6. 담기**
그릇에 면을 담고 국물과 건더기를 붓습니다. 청경채와 대파 초록 부분을 올리고 참기름 몇 방울.

![담기](짬뽕-담기.png)

## 매운맛 조절

| 단계 | 추가 |
|---|---|
| 순한맛 | 청양고추 생략, 고춧가루 2큰술 |
| 기본 | 위 레시피 그대로 |
| 매운맛 | 청양고추 4개 + 베트남 고추 3개 |
| 불맛 | 고추기름에 스리라차 1큰술, 마지막에 후추 넉넉히 |

## 실패 방지 포인트

- **고춧가루는 불 끄고 넣기** — 가장 흔한 실패 원인입니다.
- **해산물은 오래 끓이지 않기** — 오징어는 마지막 2분에 넣으면 질겨지지 않습니다.
- **국물이 밍밍하면** 소금보다 굴소스나 조개육수를 더 넣으세요. 감칠맛이 부족한 것이지 짠맛이 부족한 게 아닙니다.
- **면은 반드시 따로 삶기** — 국물에 바로 삶으면 전분이 풀려 걸쭉해집니다.
