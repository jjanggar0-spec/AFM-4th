# 물빛 화실 — 수채화 이미지 생성 앱

장면을 적고 종이 결·물 양·안료를 고르면 fal.ai의 FLUX 모델이 수채화로 그려 주는 앱입니다.

**`index.html` 파일 하나만 있으면 동작합니다.** 서버를 켤 필요가 없습니다.

## 쓰는 법

1. `index.html`을 브라우저로 엽니다.
2. 왼쪽 위 **fal.ai 키** 칸에 키를 붙여넣고 **연결**을 누릅니다.
3. 장면을 적고, 종이·물·안료·화면·붓질을 고른 뒤 **그리기**를 누릅니다.

키는 [fal.ai 대시보드 → Keys](https://fal.ai/dashboard/keys)에서 발급받습니다.
그릴 때마다 그 키의 fal.ai 계정에 요금이 부과됩니다.

## 조작

화면에서 고른 값은 FLUX가 잘 알아듣는 영문 수채화 묘사로 조립되어 전달됩니다.

| 조작 | 선택지 | 그림에 미치는 영향 |
|---|---|---|
| 종이 결 | 세목 · 중목 · 황목 | 매끈한 윤곽 ↔ 거친 결에 안료가 가라앉는 질감 |
| 물 양 | 마른붓 → 흠뻑 번짐 (5단계) | 통제된 붓자국 ↔ 번짐·블룸·백런 |
| 안료 | 페인즈그레이 · 울트라마린·번트시에나 · 봄 파스텔 · 해질녘 | 제한 팔레트로 색 통일 |
| 화면 | 정사각 · 세로 · 가로 | 1024×1024 / 768×1024 / 1024×768 |
| 붓질 | 초벌(`flux/schnell`) · 완성(`flux/dev`) | 속도·비용 ↔ 정교함 |
| 시드 | 정수 | 같은 시드 + 같은 설정 = 비슷한 그림 |

그린 그림은 아래 **그린 그림** 목록에 최근 24장까지 남고, 누르면 도화지에 다시 올라갑니다.
**내려받기**는 fal.ai 저장소에서 직접 받으므로 키가 없어도 됩니다.

## 키는 어디에 있나

| 무엇 | 어디에 | 언제 사라지나 |
|---|---|---|
| fal.ai 키 | 브라우저 **탭 저장소**(sessionStorage) | 탭을 닫으면 사라짐. **키 지우기**로 바로 삭제 가능 |
| 그림 목록·오늘 장수 | 브라우저 영구 저장소(localStorage) | 직접 비울 때까지. **목록 비우기**로 삭제 가능 |
| `index.html` 파일 | – | **키가 들어 있지 않음** |

파일을 다른 사람에게 보내도 키는 함께 넘어가지 않습니다. 대신 쓰는 사람마다 자기 키가 필요합니다.

## 보안 장치

- **통신 대상 제한 (CSP):** 페이지가 데이터를 보낼 수 있는 곳을 `https://fal.run`과 `https://*.fal.media`로만 묶었습니다.
  페이지에 이상한 코드가 끼어들더라도 키를 다른 주소로 내보낼 수 없습니다.
- **외부 문자열은 글자로만 넣습니다:** 장면 설명, 번역 결과, 목록 제목은 모두 `textContent`로 넣고 `innerHTML`은 쓰지 않습니다.
- **그림 주소 확인:** 응답의 이미지 주소가 `*.fal.media`가 아니면 표시하지 않습니다.
- **리퍼러 차단:** fal.ai 쪽으로 이 페이지 주소를 넘기지 않습니다.
- **실수 방지:** 한 브라우저에서 하루 60장을 넘기면 계속할지 한 번 더 묻습니다.
  서버에서 강제하는 한도가 아니라 실수를 막는 장치입니다.

## 한국어 장면 처리

FLUX는 한국어를 거의 이해하지 못합니다. "비 갠 오후, 골목 끝 작은 꽃집 앞에 세워둔 자전거"를 그대로 보냈더니
골목·꽃집·자전거 없이 동양식 전각이 그려졌습니다 (`예시-한국어-번역전.jpg`).

그래서 장면에 한글이 있으면 **같은 fal 키로 `fal-ai/any-llm`을 불러 영문으로 옮긴 뒤** 그립니다 (`예시-한국어-번역후.jpg`).

- 번역 모델: `anthropic/claude-haiku-4.5`
- 지시문: 사물·장소·시간·날씨·위치 관계를 그대로 옮기고, 이야기·감정·화풍 단어는 덧붙이지 않음
  (처음엔 "세워둔"이 "abandoned(버려진)"로 옮겨져 지시를 좁혔습니다. 지금은 "parked"로 옮겨집니다)
- 그리는 동안 "장면을 영어로 옮기는 중 → 물감을 번지게 하는 중"으로 단계를 보여줌
- 옮긴 문장은 그림 아래 캡션에 함께 표시
- 번역에 실패하면 한국어 원문 그대로 그리고, 캡션에 실패 사실을 알림
- 영어로 적은 장면은 번역을 건너뜀

## 알려진 한계: 그림 속 글자·서명

| 시도 | 결과 |
|---|---|
| 프롬프트에 `no text, no signature, no watermark` | 오른쪽 아래에 "Jmini" 서명이 그려짐 (부정문의 단어에 오히려 끌려감) |
| 부정 단어를 빼고 "깨끗한 흰 종이 여백" 긍정문으로 교체 | 서명이 낙서 형태로 여전히 남음 |
| 번역 지시에 "간판·책·포스터는 빈 판으로 묘사" 추가 | 번역문에 규칙이 반영되지 않음. 간판 글자가 "Flower Slorop", "FLOWEL"처럼 계속 나옴 |

초벌로 그리면 간판에 엉터리 글자가 들어가거나, 구석에 서명 같은 낙서가 들어가는 경우가 있습니다.
**지금 쓸 수 있는 방법:** 시드를 비우고 다시 그리거나, 붓질을 **완성**으로 바꿔 보세요.
완성으로 그린 그림 한 장에는 서명이 없었지만, 한 장만 보고 단정하긴 어렵습니다.

## 오류 안내

| fal.ai 응답 | 화면 안내 |
|---|---|
| `401 invalid key credentials` | 키가 거부됨 → 저장된 키를 지우고 다시 입력하게 함 |
| `403 User is locked. Reason: TOP_UP` | 계정 잔액 부족 → Billing에서 충전 |
| `has_nsfw_concepts: true` | 안전 필터 → 표현을 바꿔 달라고 안내 |
| 2분 초과 | 초벌로 먼저 그려보기 권유 |
| 인터넷 끊김 | 연결 확인 안내 |

## 확인한 것 (2026-09-11)

| 항목 | 결과 |
|---|---|
| fal.ai가 브라우저 직접 호출을 허용하는가 | 그리기·번역 모두 허용. 파일을 직접 열 때의 출처(`null`)도 허용 |
| 키 입력 → 한국어 장면 그리기 | 번역 2.0초 + 그리기 2.7초, 총 4.9초. 캡션에 영문 장면 표시 |
| 키 보관 위치 | 탭 저장소에만 있음. 영구 저장소·그림 목록에는 없음 |
| 새 탭에서 열기 | 그림 목록은 남고, 키는 사라져 다시 입력을 요구함 |
| 내려받기 | 키 없이 JPEG로 받아짐 |
| 통신 대상 제한 | `example.com`·`webhook.site` 요청과 이미지 주소로 값을 내보내는 시도가 모두 차단됨. `fal.run`만 통과 |

브라우저 테스트는 `http://127.0.0.1`에서 페이지를 열어 진행했습니다.
파일을 더블클릭해 여는 경우는 fal.ai가 해당 출처를 허용하는지까지만 확인했고, 실제 더블클릭 실행은 해보지 않았습니다.

## 서버판 (선택)

키를 브라우저에 넣지 않고 서버에만 두고 싶을 때 쓰는 방식입니다. 파일 하나짜리 버전과 화면·기능은 같습니다.

```bash
cd week-3/quest/물빛-화실
npm install
node server.js
```

→ http://localhost:3200 (`server-index.html`을 보여 줍니다)

| | 파일 하나 (`index.html`) | 서버판 (`server.js` + `server-index.html`) |
|---|---|---|
| 실행 | 파일만 열면 됨 | `node server.js` 필요 |
| 키 위치 | 쓰는 사람의 브라우저 탭 | 서버의 `%USERPROFILE%\.mulbit\.env` |
| 키 입력 | 열 때마다 입력 | 설정 파일에 한 번 |
| 사용 한도 | 브라우저의 실수 방지 확인창 | 서버가 강제 (10분 10장 · 동시 2장 · 하루 60장) |
| 그림 목록 | 브라우저에 저장 | 서버 메모리 (재시작하면 초기화) |
| 접속 범위 | 파일을 연 브라우저 | `127.0.0.1`에서만 받음 |

서버판 설정은 `.env.example`을 복사해 `%USERPROFILE%\.mulbit\.env`에 두세요.

## 키가 유출되었을 때

1. [fal.ai 대시보드 → Keys](https://fal.ai/dashboard/keys)에서 해당 키 삭제
2. 새 키 발급
3. 파일 하나 버전은 **키 지우기** 후 새 키 입력, 서버판은 `.mulbit\.env`의 `FAL_KEY` 한 줄 교체
4. 대시보드 사용량에서 모르는 생성이 있었는지 확인
