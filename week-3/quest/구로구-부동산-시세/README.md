# 구로구 · 신도림동 부동산 전월세 시세 조사

Playwright(MCP)로 부동산 사이트 3곳을 직접 열어 수집한 자료입니다.

## 산출물

| 파일 | 내용 |
|---|---|
| `신도림동-40평대-시세비교.html` | **최종 웹페이지** — 국토부·네이버·부동산원 3사 교차 비교표 |
| `신도림동-40평대-실거래가-리포트.md` | 국토부 실거래 단독 분석 |
| `구로구-전월세-시세-리포트.md` | 구로구 10개 동 전체 시세 (네이버 호가 기준) |

`캡처/` 폴더에 각 사이트 조회 화면 11장.

## 수집 방법

| 사이트 | 방법 |
|---|---|
| rt.molit.go.kr | 조건별 자료제공 → 아파트 전월세 → 구로구 신도림동 → CSV 다운로드 |
| new.land.naver.com | 지도 면적 필터 132~165㎡(40평대) → 단지 마커 시세 조회 |
| rtech.or.kr | 지도 시세 → 신도림동 → 전세 → 40평대 → 단지별 면적별 시세표 |

- 40평대 정의: 공급면적 40~49평 = **전용 99~125㎡** (네이버 기준 공급 132~165㎡)
- 수집일: 2026-09-08
- 부동산원은 자동화 대량 수집을 금지하고 있어 신도림동 40평대 9개 단지만 화면 조회 범위에서 확인했습니다.

## 로컬에서 웹페이지 보기

```
python -m http.server 8899
```
후 브라우저에서 `http://127.0.0.1:8899/신도림동-40평대-시세비교.html` 접속.
(파일을 더블클릭해 바로 열어도 정상 동작합니다.)
